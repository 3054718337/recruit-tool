# recruit-tool — 协会招新报名表数据处理小工具

协会每年招新会收到几百份报名表（问卷导出的 CSV）。本工具按
**读入概览 → 校验清洗 → 统计导出** 三步处理报名表，全程只读原始文件、不做任何修改。

## 功能路线图

- [x] 需求 1：读入与概览 —— 读入 CSV，打印总行数、每列空值数、完全重复行数（→ PR 1）
- [x] 需求 2：校验与清洗 —— 学号/邮箱校验、重复报名检查，导出带原因的「问题清单」（→ PR 2）
- [x] 需求 3：统计与导出 —— 按第一志愿分组统计、单/双志愿统计，导出干净数据（→ PR 3）

每个需求在独立分支开发，对应一个 PR 合入 main。

## 运行环境

- Python 3.10+（开发环境为 3.13）
- 依赖：pandas（`pip install -r requirements.txt`）

## 用法

```bash
pip install -r requirements.txt
python main.py data/sample.csv
```

运行后控制台打印概览与校验结果，并在 `output/` 生成导出文件：

```text
========== 报名表概览 ==========
总行数：17
每列空值数：
  姓名: 0
  学号: 0
  邮箱: 0
  志愿1: 0
  志愿2: 5
  推荐人: 4
完全重复的行：1 行（数据行 12）

========== 校验结果 ==========
发现 8 个问题行，问题清单已导出：output\问题清单.csv
  数据行 2（王芳）：学号 1120260002 出现 2 次，重复报名
  数据行 4（刘洋）：学号 1120260004 出现 2 次，重复报名
  数据行 5（陈静）：学号应为纯数字；邮箱与学号不匹配（应为 112025001x@smbu.edu.cn）
  数据行 6（赵磊）：邮箱与学号不匹配（应为 1120260006@smbu.edu.cn）
  数据行 11（冯雪）：学号 1120260004 出现 2 次，重复报名
  数据行 12（王芳）：学号 1120260002 出现 2 次，重复报名；与数据行 2 完全重复
  数据行 16（黄斌）：学号格式不符（应为 11202+入学年份末位 3-6+4 位序号，共 10 位）
  数据行 17（钱进）：学号格式不符（应为 11202+入学年份末位 3-6+4 位序号，共 10 位）
```

`output/问题清单.csv` 为 UTF-8（带 BOM）编码，Excel 可直接打开，内容是问题行的原始数据 + 数据行号 + 问题原因（一行多个原因用「；」合并）。原文件全程只读不改。

随后打印统计结果并导出干净数据：

```text
========== 志愿统计 ==========
按第一志愿分组（干净数据 9 人）：
  项目开发部: 3
  品牌传播部: 2
  综合行政部: 2
  战略关系部: 1
  创新创业部: 1
志愿填写情况：
  两个志愿都填：5 人
  只填一个志愿：4 人
干净数据已导出：output\清洗后报名表.csv（9 行）
志愿汇总表已导出：output\志愿汇总表.csv
```

三份导出文件都在 `output/` 下、均为 UTF-8（带 BOM）编码：

| 文件 | 内容 |
|---|---|
| `问题清单.csv` | 问题行原始数据 + 数据行号 + 问题原因 |
| `志愿汇总表.csv` | 第一志愿分组统计（志愿1 + 人数，按人数降序） |
| `清洗后报名表.csv` | 通过全部校验的干净数据（去首尾空格，保留原始六列） |

处理自己的报名表：`python main.py 你的文件.csv`（可用 `--output-dir` 指定输出目录）。

## 设计假设

题目没有明确的边界情况，按以下假设实现（如与真实数据冲突，以真实数据为准并更新此处）：

1. **学号**：共 10 位，结构为 `11202` + 入学年份末位（3–6，对应 2023–2026 级）+ 4 位序号（例 `1120260001`）；校验纯数字与该结构，学号非纯数字时不重复报格式错误。
2. **空值**：空字符串、纯空格、缺失字段均视为空。
3. **邮箱校验**：邮箱统一转小写后，与 `{学号}@smbu.edu.cn` 精确比对；各项校验独立执行，一行有多个问题时，原因用「；」合并写在同一格。
4. **重复报名**：同一学号出现 2 次及以上，相关行全部列入问题清单；内容完全一致的行视为误操作重复提交，导出干净数据时**保留首次出现的记录**。
5. **完全重复行**：所有字段都相同的行，在概览中计数，并标注进问题清单。
6. **志愿 2 / 推荐人为空**：属正常情况（有人只填一个志愿、没人推荐），不算数据问题。
7. **文件编码**：按 UTF-8 读取（兼容带 BOM），遇到其他编码给出明确报错。
8. **志愿取值**：协会共 7 个部门、分属 3 个中心（清单见 `data/README.md`），志愿栏填写部门名（不是中心名）；工具按部门名原文分组统计，不额外校验志愿是否在名单内。
9. **清洗动作**：导出干净数据时去掉各字段首尾空格；问题清单保留原始写法以便核对。
